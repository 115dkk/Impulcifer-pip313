# SECS 2R oracle fixtures (`s2r_*`)

Virtual room tuning 2의 3.13.0 선택 세 가지는 ADR 0015에 따라 SECS 2R을 오라클로만 사용해 구현했다. 이 저장소에는 SECS 2R 코드나 픽스처 내보내기 프로그램이 없으며, 구현은 `docs/rust/ROOM_CORRECTION.md`의 명세와 이 픽스처만 사용한다.

## Encoding

배열과 복소수, 유한하지 않은 수, `.f64` 사이드카 형식은 `README-secs2.md`의 "Encoding"과 같다. `s2r_bins.json`의 저장 빈도는 `s2_bins.json`과 같다. 모든 픽스처에는 `inputs`, `outputs`, `meta`가 있으며, `meta.weights`는 오라클의 위치 가중치, `meta.libm`은 오라클이 사용한 C 수학 라이브러리다.

## Families

| 가족 | 고정한 값 |
| --- | --- |
| `libm_probe` | 400개 입력의 `ln`, `exp(x/1000)`, `log10`, `log2`, `sqrt`, `powf(0.5)`, `sin`, `cos` |
| `rolloff_*`, `rolloff_synthetic_*` | 1/3옥타브 전력 응답, 기준 레벨, 문턱, 교차점, 롤오프 |
| `clamp_*` | 롤오프 아래 PEQ 중심 이득 제한 |
| `limit_*` | 실제 PEQ·FIR 응답 제한, 줄인 밴드와 보호 컷, 최악 빈 |
| `dc_*` | FIR DC 보정 전후와 적용 여부 |
| `dip_*`, `dip_synthetic_*` | 1옥타브 포락선, 딥 깊이, 허용 보정량, 제한 전후 설계 곡선과 진단 |
| `band_set_*` | 기본 구간과 추가 구간의 정렬·병합 |
| `masks_*` | 크기 마스크, 위상 페이드, FIR 오차 구간, 위상 점수 격자, zero 모드 PEQ 도달 구간 |
| `mask_*` | 저역 보호와 긴 모드 제한, 구간 페이드를 적용한 설계 곡선 |
| `residual_*` | PEQ 잔차와 유한하지 않은 값의 `1e12` 치환 |
| `rc_*` | 선택별·스피커별 끝단 설계 곡선, PEQ, FIR, 응답, 위상 강도와 진단 |

## Gates

`room_tuning2_s2r_libm_probe`가 Rust `f64`와 오라클의 수학 함수를 비트 단위로 비교한다. 모두 같으면 스칼라, 밴드, 마스크, 도달 구간과 진단을 비트 단위로 비교하고 곡선에 상대 1e-12와 절대 1e-12를 적용한다. 하나라도 다르면 수치에는 상대 1e-9와 절대 1e-9를 적용한다. `Limit`의 최악 빈, 줄인 밴드 인덱스와 보호 컷 수는 같은 libm에서 정확히 비교하며, 다른 libm에서는 실제 값과 기대값을 보고만 한다.

아래 값은 2026-11-07, Windows 11 x86_64-pc-windows-msvc에서 `cargo test -p impulcifer-dsp --test golden_secs2r -- --nocapture --test-threads=1`로 측정했다. 픽스처는 Debian glibc 2.41에서 만들었으며, 이 Windows 환경에서는 `ln`, `sqrt`, `powf(0.5)`만 비트 단위로 같았다. 나머지 다섯 함수가 달라 1e-9 게이트를 적용했다.

| 가족 | 게이트 | 관측한 최대 절대 오차 | 관측한 최대 상대 L2 오차 |
| --- | --- | ---: | ---: |
| libm probe | 함수별 비트 비교 | 다섯 함수 불일치 | 해당 없음 |
| band set | 상대 1e-9, 절대 1e-9 (같은 libm에서는 비트 동일) | 0 | 0 |
| masks | 상대 1e-9, 절대 1e-9 (같은 libm에서는 비트 동일) | 2.2737367544323206e-13 | 6.652799355587308e-17 |
| rolloff | 스칼라 상대 1e-9, 절대 1e-9 (같은 libm에서는 비트 동일) | 6.821210263296962e-13 | 4.2934407425396315e-16 |
| clamp | 상대 1e-9, 절대 1e-9 (같은 libm에서는 비트 동일) | 0 | 0 |
| limit | 수치 상대 1e-9, 절대 1e-9; 정수 결정은 보고만 함 | 4.440892098500626e-16 | 1.5065656150329976e-15 |
| DC correction | 상대 1e-9, 절대 1e-9, 적용 여부 정확히 같음 | 1.3552527156068805e-20 | 4.851060544800653e-20 |
| dip limit | 상대 1e-9, 절대 1e-9, 진단 종류와 순서 정확히 같음 | 6.821210263296962e-13 | 4.360486500742148e-15 |
| low-protection design mask | 상대 1e-9, 절대 1e-9 | 4.263256414560601e-14 | 2.842924265171789e-15 |
| residual | 상대 1e-9, 절대 1e-9, 모든 값 유한 | 2.6645352591003757e-14 | 2.9169934962049308e-16 |
| RC design curve and complete notes | 상대 1e-9, 절대 1e-9; 정수 결정은 보고만 함 | 4.263256414560601e-14 | 3.2620804220457383e-15 |

끝단 `rc_*`의 PEQ 정련은 `s2_*`와 마찬가지로 첫 평가 뒤 선형대수 계산이 다르게 처리되기도 하므로 PEQ, FIR, 응답, 위상 강도는 보고만 한다. 이 Windows 실행에서 설정별 최대 차이는 다음과 같았다.

| 설정 | PEQ f0 | PEQ Q | PEQ gain | FIR | 응답 dB | 위상 강도 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| `off` | 2.641774393e2 | 1.234980491e1 | 3.175853158e1 | 5.054190658e-4 | 2.001949010 | 0 |
| `dip` | 3.267620189e2 | 1.776784555e1 | 1.405485902e1 | 5.991484337e-4 | 1.396361186 | 0 |
| `protect` | 6.249879281e1 | 1.205230224e1 | 3.000079814 | 6.264178161e-4 | 6.528662133e-1 | 0 |
| `bands` | 3.279458109e2 | 1.241853735e1 | 3.332511092e1 | 8.816952243e-4 | 1.947271418 | 0 |
| `all` | 1.587310403e1 | 3.164880375 | 1.035219351e1 | 1.113121823e-3 | 1.284493722 | 0 |

저역 보호 진단의 `reduced`와 `cuts`는 두 번째 PEQ를 제한할 때 만든 결과를 최종 FIR 응답 제한까지 이어서 누적한 값이며, `limited`도 최종 응답을 기준으로 한다. 오라클이 만든 데모 픽스처에서는 최종 FIR 응답 제한이 새로 줄인 밴드가 없었다. 다른 libm에서 PEQ 정련 결과가 달라져 이 결정이 바뀌면 게이트가 실제 값과 기대값을 보고한다.
