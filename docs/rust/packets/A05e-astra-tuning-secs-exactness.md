## 3. Pre-echo diagnostic: measure the direct sound, not the largest peak

The "pre-echo" warnings on the demo (SL −5.2 dB, SR −3.2 dB, BR −3.7 dB) are a measurement artefact: in a contralateral ear a later reflection can be larger than the head-shadowed direct sound, so the largest-|h| peak is not the direct sound. The **untuned** room EQ output already shows the same values on those channels (−0.1 to −11.5 dB); below 300 Hz the tuned output's pre-echo is −29 to −40 dB. Fix: the direct sound is the first peak by `peaks::first_peak_index(data, 0, None, 0.12589)` (−18 dB threshold, as the arrival code uses); pre-echo = max |h| over `[0, direct − 0.5 ms]` relative to |h(direct)|. Measure it on the untuned and on the tuned BRIR of each channel, and warn (`cli_room_tuning_preecho`) only when the tuned value exceeds −30 dB **and** is at least 6 dB above the untuned value of the same channel. The demo must not warn; report per channel untuned/tuned.

## 4. Replace the "weak" rule

LF EDT and median excess group delay of the in-ear BRIR are not reliable judges here: SECS's own filter, applied at its own measurement point, also lengthens LF EDT and raises the median excess group delay for some demo speakers (measured outside this task with SECS itself: e.g. BR omni EDT 411 → 598 ms, FR omni median excess GD 3.3 → 6.9 ms), so the rule fired for every demo speaker without indicating a defect. Keep both numbers in the readme as information. `cli_room_tuning_weak` instead answers the question it was meant for — do the room files represent the ears? — with the measure you already computed: per speaker and ear, the RMS difference between the omni magnitude at that ear position and the BRIR magnitude of the same ear, both 1/6-octave smoothed and level-matched over 100–300 Hz, over 30–300 Hz; warn when the mean over the two ears exceeds 4 dB. Report the demo values (you measured 1.6–3.5 dB, so no warning is expected).
