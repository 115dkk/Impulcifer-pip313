# 일관성 · UX — Nielsen 휴리스틱 / 스킨 비교 / 위계 / 패리티

명암비 외의 생존 결함과 기각 항목, 그리고 소스 대조로 정정한 거짓 양성을 정리한다.
이 절의 항목은 대부분 폴리시(LOW)이거나 디자인 결정을 요하는 MEDIUM이며, 이번 PR에서는 권고로만 남기고
코드 반영은 보류했다(주관성·레이아웃 변경 위험).

## [MEDIUM] BRIR 생성 CTA 색이 스킨 간 불일치 (Stable=초록, Studio=파랑)

- **기준**: Nielsen #4 일관성 / 토큰·브랜드 일관성. **증거**: `stable_impulcifer_dark_bottom`, `studio_impulcifer_dark`.
- **내용**: 동일한 'BRIR 생성' 액션이 Stable에서는 하단 풀너비 **초록**(ok 토큰), Studio에서는 우상단 **파랑**(accent) 버튼.
  같은 명령에 두 브랜드 색이 매핑된다. (명암비 문제는 없음 — 둘 다 흰 텍스트가 대형 CTA로 충분.)
- **권고**: 주 CTA 색을 한 토큰으로 표준화(권장: accent). 초록(ok)은 완료/성공 상태로 한정. 어느 색을 정본으로 할지
  사용자 결정이 필요해 이번엔 보류.

## [MEDIUM] 처리옵션 가이드 패리티 격차 — Studio는 카드+설명, Stable은 라벨만 체크박스

- **기준**: Nielsen #6 재인 우선 / 스킨 간 기능 패리티. **증거**: `stable_impulcifer_dark(_bottom)`, `studio_impulcifer_dark(_bottom)`.
- **내용**: Studio는 각 옵션(룸 보정/헤드폰 보정/이퀄라이제이션/가상 베이스)에 한 줄 설명을 단다
  (예: '저음이 부족한 구간에 이상적인 저역 응답을 더합니다'). Stable은 같은 기능을 설명 없는 체크박스로 노출 —
  특히 '가상 베이스 활성화'는 힌트 0. 단, Stable도 일부 항목엔 괄호 힌트가 있어 완전 무설명은 아니다.
- **권고**: Studio가 쓰는 기존 i18n 설명 키를 Stable 체크박스 아래 muted 서브라벨(fg-2)로 재사용. (레이아웃 변경 수반 → 보류.)

## 빨강 녹음 버튼 명암비 — 거짓 양성

적대적 검증 단계에서 한 검토자가 Studio '녹음 시작' 빨강 버튼의 흰 텍스트를 **2.9:1(미달)**로 보고했다.
그러나 이는 채움색을 err 다크 토큰 `#fb594d`로 **가정**한 결과였다. GUI 소스를 대조하니
`gui/skins/studio_recorder_tab.py`가 `cta_color="#dc2626"`(더 진한 빨강)을 명시한다. 흰색 `#ffffff` 기준
`#dc2626` 위 대비는 **약 4.8:1로 AA 통과**다(`#f3f5f7` 기준으로도 ~4.4:1).

→ 본 결함은 코드 그라운딩으로 반증되어 **수정 대상에서 제외**했다. 같은 버튼의 "빨강=정지 시멘틱" 우려는
별개로 위 LOW 표에 남겼다(방어 가능한 폴리시).

이는 스크린샷만으로 색 토큰을 추정할 때의 위험을 보여주는 사례이며, 향후 색 관련 결함은 반드시 테마/위젯
소스와 대조해야 한다.

## 기각된 결함 (11건) — "나빠 보이지만 실제로는 괜찮음"

적대적 재검증에서 증거 부족·거짓·의도된 유효 선택으로 판정되어 기각된 항목.

1. 헤어라인 구분선(line-soft)이 카드 위에서 3:1 미만 → 비텍스트 장식 경계라 SC 1.4.11 비해당.
2. Studio '변경' 링크가 타깃 크기(SC 2.5.8) 미달 → 실제 클릭 영역/행 높이로 통과.
3. Studio '변경' 링크가 우측 창 가장자리에 붙음 → 충분한 패딩 확인, 비문제.
4. 녹음 진행/상태 피드백 없음 → 정적 idle 화면만 캡처됨, 런타임 상태표시는 별도 구현 존재(`gui/recording_status.py`).
5. Stable 레이아웃이 비어 보임(데드 스페이스) → 의도된 여백, 결함 아님.
6. Studio 설정 라벨-컨트롤 수직 정렬 어긋남 → 표준 설정 행 패턴, 비문제.
7. Stable 탭이 카드 경계 없이 섹션 제목만 → 의도된 스킨 차별화(Stable=플랫 폼).
8. Studio 토글 행 중앙 데드 스페이스 → 좌제목-우chevron 표준 disclosure 행, 비문제.
9. 스킨 토글 비선택 'Stable' 라벨이 라이트에서 거의 안 보임 → 재검증 결과 가독, 기각.
10. 3차 muted 텍스트(fg-3)가 라이트 카드에서 3:1 미만 → 보조 텍스트라 해당 SC 미적용 수준.
11. 녹음 주 액션이 스킨 간 강하게 갈림(Stable 소형 파랑 inline vs Studio 풀 빨강) → 스킨 차별화 의도, 기각.
