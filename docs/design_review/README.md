# GUI 디자인 적대적 리뷰 — Stable / Studio 스킨

`gui/`의 두 스킨(**Stable** = `CTkTabview` 기반 컴팩트 레이아웃, **Studio** = 사이드바 + 카드 레이아웃)을
실제 렌더링 스크린샷 기준으로 적대적(adversarial)으로 리뷰한 결과 문서다. 작성일 2026-06-13, 대상 버전 v2.7.8.

## 방법론

근거가 없는 인상비평을 배제하기 위해 다음 절차를 거쳤다.

1. **증거 수집** — `gui.modern_gui.ModernImpulciferGUI`를 실제 디스플레이에서 구동하여
   `Stable × Studio × {녹음·처리·설정·정보} × {dark·light} × {상단·하단 스크롤}` 조합으로 30장의
   스크린샷을 캡처했다(2000×1400px, 논리 해상도 1000×700의 2× HiDPI). 캡처 스크립트는
   `_verification/design_screens.py`이며, 이 디렉터리는 `.gitignore` 대상이라 저장소에는 포함되지 않는다.
2. **다중 렌즈 리뷰** — 6개의 독립 렌즈(① WCAG 2.2 명암비, ② 타깃 크기/간격, ③ Nielsen 휴리스틱,
   ④ 시각 위계/타이포그래피, ⑤ dark/light 패리티, ⑥ 스킨 비교 + 오디오 도구 컨벤션)가 각자
   스크린샷을 직접 판독해 결함 후보를 제출했다. 명암비는 눈대중이 아니라 디자인 토큰
   (`gui/theme/__init__.py`의 `COLORS`)의 sRGB 상대휘도로 **실제 계산**했다.
3. **적대적 재검증** — 각 결함마다 별도의 회의적 검토자가 인용된 스크린샷의 픽셀을 다시 읽어
   반증을 시도했다. 기본값은 "기각"이며, 증거가 명확히 뒷받침할 때만 확정/등급조정으로 살아남는다.
   34건의 후보 중 **23건이 생존, 11건이 기각**되었다.
4. **소스 대조 정정** — 생존 결함도 GUI 소스와 대조했다. 그 결과 명암비 후보 한 건(빨강 녹음 버튼)이
   잘못된 색 가정에 기반한 **거짓 양성**임이 드러나 정정했다([02-consistency-ux.md](02-consistency-ux.md) 참조).

## 심각도 요약 (재검증 후 등급)

| 심각도 | 건수 | 핵심 항목 |
|--------|------|-----------|
| HIGH | 2 | 드롭다운 흰 텍스트 명암비, 정보 탭 버전 문자열 명암비 |
| MEDIUM | 3 | 활성 사이드바 라벨 명암비, BRIR 생성 CTA 색 불일치, 처리옵션 가이드 패리티 격차 |
| LOW | 12 | 색 시멘틱, 칩 체계, 파일행 어포던스, 다크/라이트 가중치, 용어 불일치 등 폴리시 |
| 기각 | 11 | "나빠 보이지만 실제로는 괜찮음" — 아래 별도 절 |

> 같은 결함이 여러 렌즈에서 중복 검출된 경우(예: 드롭다운 명암비는 ①·③·⑥ 세 렌즈에서 검출) 한 건으로 병합했다.

## 한계

잔상·미세 렌더링과 마찬가지로, 명암비 수치는 토큰 기반 계산이지만 **실제 인지 가독성은 사용자 디스플레이
(감마/패널/주변광)에 의존**한다. 또한 본 리뷰는 정적 스크린샷 기준이라 hover/focus/open 등 인터랙션 상태,
실제 클릭 가능 영역(예: 카드 전체가 토글을 받는지)은 픽셀만으로 단정할 수 없어 해당 항목은 보수적으로
등급을 낮췄다.
